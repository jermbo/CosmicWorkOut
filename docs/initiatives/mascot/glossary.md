# Glossary: Mascot

- **Mascot** — the character of CosmicWorkOut. It is the favicon, the image in the header, and it shows in the animations.
- **Pet** — the part of the Mascot that you interact with. It has a mood and a level, and the Pet toggle turns it on or off.
- **Streak** — the number of days or weeks in a row with a record of one kind, such as habits. Each kind has its own streak. Today the project glossary has one streak, for workouts.
