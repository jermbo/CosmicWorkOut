# Glossary: Custom Activity Types

- **Activity type** — one value in your own list of activities, such as Cardio or Mowing. This changes the meaning in the project glossary, where it is a value in a fixed list.
- **Hidden activity type** — a type that you took out of the picker and the Activity Mix chart in Settings. Its entries stay saved.
