# CosmicWorkOut — Project Wiki

> A simple, offline-first fitness tracking app built for people who want to follow a structured program without the noise.

---

## How to read this wiki

Docs are organized by **altitude**. Start high to understand *why*, work down to understand *what* and *how*.

| Level | Folder | Purpose |
|-------|--------|---------|
| 30k | [vision/](vision/) | North star — what we're building and why. Every decision gets judged against this. |
| 15k | [architecture/](architecture/) | How the system is structured. Data, tech, offline strategy. |
| 5k | [requirements/](requirements/) | What needs to be built. User stories per feature area. |
