# v1.2.0 — Habit Log Redesign & Dashboard Polish

This version deepens the habit experience introduced in v1.1.0. It unifies the "Daily check-in" and "Your habits" sections into a single, more expressive habit log, surfaces habit history on the calendar, and closes out the remaining dashboard gaps from v1.1.0.

## Design North Star

> "Tap tap tap, phone back in pocket."

Same as v1.1.0 — every interaction must be completable with minimal taps. The habit section redesign must not add friction; it should feel faster and more satisfying.
