# Habits

Habits are the small things that you want to do each day: water, reading, a few quiet minutes. The Habits screen is a daily check-in for the logging date. It is off until you turn it on.

## The check-in

Each habit is a tile in its own colour. The tile shows the value of the day over the goal, such as `3/4`, and a row of progress blocks under it. A goal of 12 or less gets one block for each unit; a larger goal gets ten blocks, one for each tenth. A tile with no value yet has diagonal stripes.

You tap or hold plus and minus, or you tap the number to type an exact value. A Yes / No habit has one button: **Mark done**, which becomes **✓ Done**. When a habit reaches its goal, the tile jolts and flashes, with a `success` buzz.

A minutes habit moves by 5. Any other habit moves by about a tenth of its goal, as a simple number: 4 cups by 1, 500 words by 50.

## When a habit is done

A habit with a goal is done when the value reaches the goal; with no goal, at any value above zero. The Habits card on the Overview counts the habits that are done, not the ones that you touched.

## The five types

| Type     | You log                            | Blocks |
| -------- | ---------------------------------- | ------ |
| Times    | How many times; no unit            | Yes    |
| Minutes  | How long                           | Yes    |
| Count    | A number with a unit that you type | Yes    |
| Yes / No | Done or not done                   | No     |
| Mood     | A value from −5 to +5              | No     |

## Built-in habits

The app adds five habits on the first start: Water (4 cups), Coffee (2 cups), Meditation (20 minutes), Writing (500 words), and Reading (30 minutes). It adds them only once; after that they are yours.

## Your own habits

In Settings → Habits you make, edit, reorder, turn off, and colour habits. A habit that is off hides, and its logs stay. Each habit has one value for each date, and each tap overwrites it. The scale at the top of the screen is [Mood](mood.md), a habit with its own rules.

### Example

Your Water goal is 4 cups, so the tile has four blocks. You tap plus three times in the morning: `3/4`, three blocks on. In the evening you tap once more. The fourth block fills, the tile flashes, and the Overview card counts one more habit done.
